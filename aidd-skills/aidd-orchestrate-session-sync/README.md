# aidd-orchestrate-session-sync

Motor universal e deterministico de sincronizacao de historico de sessao para o ecossistema AIDD.

## Como Usar via CLI

```powershell
# Execucao direta no terminal
faz-session

# Gerar tanto JSON quanto Markdown
faz-session --format all

# Especificar sessao manualmente
faz-session --id bbeab338-3ea3-4547-b3d7-a8a8fd99e795
```
