# Regras de Governança: aidd-materialize-tutorial-stitch

## 1. Diretrizes Invioláveis
- **Zero Mocks/Stubs:** Todo código de união de tutoriais e código fonte deve ser executável e funcional.
- **Estruturação Determinística:** Tutoriais devem possuir introdução contextual, passos reproduzíveis, código fonte correspondente e verificações de sucesso.
- **Passagem de Ponteiros:** Utilizar manifesto JSON e hashes SHA-256 para referenciar artefatos de mídia ou fontes externas.
- **Concisão Extrema:** Documentação técnica objetiva, sem prolixidade, priorizando comandos e snippets acionáveis.
