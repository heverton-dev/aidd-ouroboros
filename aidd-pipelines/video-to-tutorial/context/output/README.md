# Contexto de Saída: video-to-tutorial

Este diretório recebe os tutoriais gerados, documentações e manuais passo a passo derivados do vídeo.

## Contrato de Dados
- **Entregáveis:** Artigos Markdown, capturas chave anotadas, diagramas Mermaid e checklists de execução.
- **Envelope de Entrega:** Estrutura documentada com manifesto de exportação e rastreamento de fonte.
- **Persistência:** Documentos finais consolidados podem ser exportados para a base de conhecimento.
