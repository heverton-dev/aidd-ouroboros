# Contexto de Saída: _e2e-smoke

Este diretório recebe os artefatos de saída do teste de fumaça (smoke test) E2E.

## Contrato de Dados
- **Entregáveis:** Manifests de validação, status de execução e relatório consolidado de sanidade do grafo.
- **Envelope de Entrega:** Estrutura inspecionada pelos gates de auditoria do Ouroboros.
- **Persistência:** Ficheiros dinâmicos são limpos ou ignorados.
