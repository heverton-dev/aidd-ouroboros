# Contexto de Handoffs: _e2e-smoke

Este diretório gerencia a transição sintética de dados entre nós durante a execução de smoke tests do ecossistema.

## Contrato de Dados
- **Formato:** Manifests sintéticos de handoff e assinaturas de teste.
- **Integridade:** Validação do fluxo de handoff sem sobrecarga de processamento.
- **Persistência:** Não versionado.
