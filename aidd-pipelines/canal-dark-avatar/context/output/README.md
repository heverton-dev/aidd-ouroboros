# Contexto de Saída: canal-dark-avatar

Este diretório recebe os entregáveis finais gerados pelo pipeline `canal-dark-avatar`.

## Contrato de Dados
- **Entregáveis:** Vídeos sintetizados, avatares sincronizados, legendas (`.srt`/`.vtt`) e relatórios de renderização.
- **Envelope de Entrega:** Estrutura acompanhada de hash de integridade e metadados de execução.
- **Persistência:** Entregáveis multimídia pesados são ignorados pelo Git, mantendo apenas este contrato e logs estruturados.
